# Privacy

Kali Squad is designed for local-first operation.

- Configurations and servers stay on device by default
- Cloud sync is optional and user-controlled
- Diagnostics and logs redact sensitive fields before share/export
- No unnecessary telemetry in Phase 1 foundation

What stays local:
- Configurations
- Servers
- Connection history (when enabled)
- Application preferences

What may leave the device (only if user enables cloud):
- Encrypted configuration backups
- Device registration metadata
